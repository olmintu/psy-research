# Локальный запуск прототипа

1. Открой терминал в этой папке (где лежит `index.html`).
2. Запусти сервер:  `python -m http.server 8000`  (на Mac/Linux: `python3 -m http.server 8000`)
3. Открой в браузере: http://localhost:8000

Двойной клик по `index.html` тоже работает, но через сервер ближе к тому, как сайт будет вести себя на GitHub Pages.

## Что уже изменено относительно старого проекта
- Удалён ИИ-ассистент (кнопка, окно чата, стили, код, ссылка на Apps Script с Gemini).
- `STORAGE_KEY` сменён на `survey_proto_v1`, чтобы не пересекаться с сохранениями старого проекта.
- `GOOGLE_URL` пуст: **ответы никуда не отправляются**. Когда будет готова новая таблица и Apps Script, вставь адрес в `js/app.js` (константа `GOOGLE_URL`).
- Расчёты Братуся, Мильмана и ИПЛ не тронуты (проверено сравнением отчёта на одних и тех же данных).

## Режим разработчика
Введи `dev` в поле ФИО: отправка в облако отключена, появляется кнопка автозаполнения.
